### 문제 설명

<p>Từ cặp số (a, b) gồm 2 số nguyên dương, có thể sử dụng 1 trong 3 phép biến đổi sau để tạo ra cặp số mới </p>

<ul>
	<li>(a,b) → (a, a+b) </li>
	<li>(a,b) → (a+b, b) </li>
	<li>(a,b) → (b,a) </li>
</ul>

<p>Bắt đầu từ cặp số (1, 1) hãy dùng ít phép biến đổi nhất để tạo ra một cặp số có chứa số N.</p>

### 입력 

 <p>Dòng đầu chứa số test T. Tiếp theo là T test, mỗi test chứa một số 1 ≤ N ≤ 10<sup>6</sup>.</p>

### 출력 

 <p>Ứng với mỗi test, in ra trên một dòng số bước biến đổi ít nhất.</p>
